# Security, Styx

- This repo is private. It is not for public release without a
  separate review.
- No secrets, keys, tokens, passwords, or signed URLs are in
  this repo. If one is found, remove it, rotate it, and do not
  push the history containing it.
- No installers, hooks, or MCP installs are in this repo.
  Install scope is SKILL.md only.
- Upstream skill bodies are not copied here. Upstream credit
  and licenses stay with their original repos.
- Personal details, internal hosts, IPs, and bot identifiers
  are not in this repo. If one appears, remove it before push.
